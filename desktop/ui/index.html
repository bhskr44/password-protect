How to use Password Protect

Encrypting is called locking here, and decrypting is called unlocking.

Lock (encrypt) a file or folder

  1. Open the Protect tab.
  2. Drag the file or folder into the window, or choose Choose file or Choose folder.
  3. Type a password, then type it again. Use at least 8 characters.
  4. Tick Delete the original once the locked copy has been checked if you no longer want the unprotected copy.
  5. Choose Lock.

A new file ending in .locked appears next to the original. That is the file to store or send. If you kept the original, that copy is still unprotected.

Unlock (decrypt) a file or folder

  1. Double-click the .locked file, or drag it into the Protect tab.
  2. Type the password.
  3. Choose Unlock.

The original appears next to the locked file, with its original name. A locked zip is extracted as well.

Send a locked file to someone

  1. Send the .locked file by any route.
  2. Tell them the password a different way, such as a phone call. Never put the password in the same message as the file.

Files move freely between Windows and Mac.

Prove that nothing changed

The seal and SHA-256 identify the contents. The same contents always give the same seal, and any change gives a different one.

  1. When locking, choose Copy SHA-256 and keep it.
  2. On the other computer, open the locked file and choose Check without unlocking.
  3. Type the password, paste the SHA-256 and choose Check.

You see Match or Does not match, and nothing is unlocked. To check a file that is not locked, use the Check tab.

See who locked or unlocked what

The History tab lists each action on this computer, with the time, the person logged in, the item and its seal. Each computer keeps its own history. A locked file also carries who locked it and when, shown when it is unlocked or checked.

If something goes wrong

Wrong password, or the file is corrupted
Check the password, including capital letters. If it still fails, the file may have been damaged. Ask for a fresh copy.
Already exists
Something with that name is already in the folder, and it is never overwritten. Move or rename it, then try again.
Forgotten password
The locked file cannot be opened by anyone. Use another copy of the original if you have one.
